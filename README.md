# 🔥 DevRoast

> Paste your code. Get roasted.

DevRoast is a web app that takes your code and returns a **brutally honest, sarcastic AI review** — with a score from 0 to 10 and line-by-line feedback on everything you did wrong (and why you should feel bad about it).

Built live during **[NLW (Next Level Week)](https://rocketseat.com.br)** by Rocketseat 🚀

---

## ✨ Features

- 📋 **Paste any code** — supports multiple languages
- 🌶️ **Roast mode** — maximum sarcasm, enabled by default
- 🎯 **Score 0–10** — the lower, the more you should reconsider your career choices
- 📝 **Line-by-line feedback** — no bad line goes unpunished
- 🏆 **Shame leaderboard** — the worst code ever submitted, immortalized forever

---

## 🚀 Running locally

You'll need [Bun](https://bun.sh) installed.

```bash
bun install
bun dev
```

Then open [http://localhost:3000](http://localhost:3000) and prepare to be humbled.

---

## 🛠️ Scripts

```bash
bun dev    # start dev server
bun build  # production build
```
